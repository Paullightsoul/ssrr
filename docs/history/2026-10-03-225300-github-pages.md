# Публикация приглашения на GitHub Pages

## Решения
- Статика отдаётся с ветки `main` репозитория `Paullightsoul/ssrr`, без чужого CNAME: иначе Pages ушёл бы на `vt.shizuka.my.id`.
- Ссылка на приглашение собирается от текущего origin, чтобы форма работала на `github.io`.

## Что сделано
- Склонирован `Shizu-ka/Date-Valentine-Invitation`, убраны CNAME и чужой счётчик Umami.
- Репозиторий https://github.com/Paullightsoul/ssrr, страница https://paullightsoul.github.io/ssrr/

## Итерации
- Первый push не прошёл из-за shallow-клона (`index-pack failed`); после `fetch --unshallow` ветка `main` ушла на origin.
- Pages несколько десятков секунд отвечал 404, пока сборка была в статусе `building`.

## Диалог
Пользователь попросил найти HTML-приглашение на свидание, склонировать его в этот репозиторий и выложить на домен GitHub. Страница открывается по адресу https://paullightsoul.github.io/ssrr/.
